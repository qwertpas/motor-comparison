# Motor comparison

Interactive comparison of motor mass, diameter, motor constant and geared power density.

Published at https://qwertpas.github.io/motor-comparison/.

The X axis supports mass and diameter. Diameter uses published bell/outer dimensions where collected; otherwise it uses the nominal diameter encoded in the motor size and is marked approximate. The Y axis supports motor constant and power density. Sources and calculation assumptions accompany each entry.

`index.html` is the self-contained website. `motor-comparison.html` is the same file for offline download. GitHub Pages serves the root of the `main` branch.
